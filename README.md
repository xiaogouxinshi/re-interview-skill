# re-interview · 面试复盘 Skill

一个可复用的面试复盘技能：用户只要上传「岗位 JD」+「面试会议纪要」，说一句「帮我进行面试复盘」，即可自动生成两份可打印、可直接参考的 HTML 交付文件。

## 它能做什么

触发后自动产出两个文件：

1. **文件一《本轮面试复盘》**：逐题解析
   - 每道题的**考察点**（面试官真正在测什么）
   - 回答的**结构与内容问题**
   - 可保留的思路
   - 如何继续精进
   - 该岗位**专业人士会怎么答**（示范回答骨架）
   - 结尾总结「本轮需改进」+「下轮注意要点」

2. **文件二《下轮面试准备》**：下一轮备战
   - 要守住的几张牌（对应本轮被记下的疑虑）
   - 高频问题的**答案骨架 + 关键词 + 内容方向提示**
   - 下一轮需补充的**专业知识与认知**（按模块 + 附面试可能追问）

## 使用方式（两种，均支持开源）

### 方式一：链接即调用（免安装，推荐开源分享）

本方法把 `SKILL.md` 当作一份**自包含的开源提示词**，任何 AI 都能用，无需安装。

把本仓库托管到 GitHub 后，只需把 raw 链接 ＋ 一句指令复制给 AI：

> 请遵循以下链接中的方法，帮我做一次面试复盘：
> `https://raw.githubusercontent.com/xiaogouxinshi/re-interview/main/SKILL.md`
>
> 我已附上岗位 JD 和面试纪要，请按该方法生成《本轮面试复盘》与《下轮面试准备》两份文件。

随后上传两个文件：
- **岗位 JD**（岗位职责、任职要求等）
- **面试纪要 / 逐字稿**（含「面试官」「我」的问答记录）

> 缺任一文件时，AI 会先向你索要，不会臆造内容。

### 方式二：本地 Skill 安装（TRAE 用户）

把本仓库克隆到 TRAE 的 skills 目录：

```bash
git clone https://github.com/xiaogouxinshi/re-interview.git <workspace>/.trae/skills/interview-review
```

或手动把 `SKILL.md` 放到 `.trae/skills/interview-review/SKILL.md` 路径。

安装后，输入「帮我进行面试复盘」即自动触发，无需粘贴链接。

## 特点

- **跨岗位通用**：不绑定某个行业，会从 JD 自适配该岗位的核心风险点（动机稳定性 / 硬性要求 / 岗位认知 / 能力叙事）。
- **剥离语音转写误差**：忽略口误、错别字，只评估回答的逻辑骨架与内容质量。
- **HR 视角**：定位「失分根因」（能力不足 / 动机没想透 / 认知浅），而非泛泛而谈。
- **可执行落点**：结论落到「本轮需改进」+「下轮注意」两条，能照着做。
- **自包含 HTML 交付**：内联 CSS、可打印，自动跟随对话语言（中/英）。
